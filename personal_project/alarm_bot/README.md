# 🔔 Discord 알림 봇 (Discord Notification Bot)

동양미래대학교 홈페이지의 공지사항과 학식 식단표를 확인해 Discord 채널로 알려 주는 파이썬 봇입니다. 대학 공지와 학과 공지(컴퓨터소프트웨어공학과, 정보통신공학과)에 새 글이 올라오거나 글이 삭제되면 알림을 보내고, 평일 아침마다 오늘의 한식 메뉴를 전송합니다.

## 🌟 주요 기능

* **새 공지 알림**
    * 게시판 세 곳을 1분 간격으로 확인하고, 새 공지가 올라오면 제목과 링크를 전송합니다.
    * 대학 공지는 테스트·정통과·컴소과 채널로, 학과 공지는 테스트 채널과 해당 학과 채널로 전송합니다.
    * 새 공지가 여러 개이면 개수를 먼저 안내한 뒤, 오래된 공지부터 차례로 전송합니다.
    * 공지 번호가 아니라 글의 고유 ID로 비교하므로, 게시판 번호가 다시 매겨져도 이미 알린 공지를 다시 보내지 않습니다. 상단에 고정된 공지는 비교 대상에서 제외합니다.
* **공지 삭제 알림**
    * 이전에 확인한 공지가 첫 페이지에서 사라지면 상세 페이지를 열어 실제로 삭제되었는지 확인합니다.
    * 두 번 연속으로 삭제가 확인되면 "N번 공지가 삭제되었습니다" 알림을 보냅니다. 새 글에 밀려 다음 페이지로 넘어간 공지는 알리지 않습니다.
* **공지 상태 저장**: 확인한 공지 목록을 `bot_data/notice_state.json`에 저장하므로, 봇을 다시 시작해도 이전 상태에 이어서 비교합니다. 상태 파일이 없는 첫 실행에서는 현재 목록만 저장하고 알림은 보내지 않습니다.
* **야간 확인 중지**: 밤 10시부터 아침 6시까지는 공지 확인을 멈춥니다.
* **오늘의 한식 메뉴**
    * 매일 오전 9시에 학식 식단표에서 오늘의 한식 메뉴를 찾아 테스트·정통과 식단표·컴소과 식단표 채널로 전송합니다.
    * 한식 메뉴가 없는 날에는 메뉴가 없다고 안내하고, 식단표에 날짜가 없는 주말에는 전송하지 않습니다.
    * 식단표를 불러오지 못하면 10분 뒤에 다시 시도합니다.
* **`!식단표` 명령어**: 채널에 `!식단표`를 입력하면 요일별 고정 메뉴와 이번 주 한식 메뉴를 보여 줍니다.
* **오류 처리**: 홈페이지 요청이 실패하면 15초 간격으로 최대 5번 다시 시도하고, 실패할 때마다 오류 내용을 Discord 채널로 알립니다. 작업 도중 예외가 발생하면 테스트 채널에 알린 뒤 모든 작업을 다시 시작합니다.

## 🛠️ 기술 스택

* **언어**: Python
* **라이브러리**: `discord.py`, `aiohttp`, `beautifulsoup4`, `lxml`, `python-dotenv`
* **테스트**: `pytest`, `pytest-asyncio`

## 🚀 프로젝트 실행 방법

프로젝트를 실행하려면 다음 단계를 따라 주세요.

1.  **필수 라이브러리 설치**:
    ```bash
    pip install -r requirements.txt
    ```
2.  **환경변수 파일 생성**:
    * `.env.example` 파일을 복사해 `.env` 파일을 만들어 주세요.
    ```bash
    cp .env.example .env
    ```
    * `.env`에 Discord 봇 토큰과 채널 ID를 입력해 주세요.
    * `.env` 파일은 외부에 공개하거나 Git에 commit하면 안 됩니다.
3.  **환경변수 항목**:
    * `DISCORD_BOT_TOKEN`: Discord 개발자 포털에서 발급받은 봇 토큰
    * `TEST_CHANNEL_ID`: 테스트 및 오류 메세지를 보낼 채널 ID
    * `ICE_CHANNEL_ID`: 정통과 공지 채널 ID
    * `CSE_CHANNEL_ID`: 컴소과 공지 채널 ID
    * `MENU_ICE_CHANNEL_ID`: 정통과 식단표 채널 ID
    * `MENU_CSE_CHANNEL_ID`: 컴소과 식단표 채널 ID
    * `NOTICE_STATE_FILE`: 공지사항 상태 저장 파일 경로(선택사항)
4.  **봇 실행**:
    ```bash
    python src/newAlramBot.py
    ```

    * `.env`와 `bot_data/`는 `src/`가 아닌 프로젝트 루트에 있어야 합니다.
    * 로그는 실행한 위치의 `bot_log/`에 기록됩니다. 프로젝트 루트에 `bot_log/`를 만든 뒤 루트에서 실행해 주세요.

## 📁 디렉터리 구조

```
alarm_bot/

├── test/                # pytest 테스트와 게시판 HTML 픽스처
├── practice/            # 봇에서 사용하지 않는 연습용 스크립트
├── requirements.txt
├── .env.example
└── README.md
```

## 🧪 테스트 실행 방법

테스트는 `test/` 디렉터리에 있으며, 실제 `.env`의 토큰·채널·상태 파일을 사용하지 않습니다.

```bash
pip install -r test/requirements.txt

# 오프라인 테스트: test/fixtures의 실제 게시판 HTML을 로컬 서버로 응답
pytest test/

# 실서버 테스트: 학교 게시판에 실제로 요청하여 HTML 구조 변경 여부 확인
pytest test/ -m live
```

## ⚠️ 주의사항

* 봇 토큰은 외부에 노출되지 않도록 주의해야 합니다. 환경 변수로 관리하는 것을 권장합니다.
* 채널 ID는 봇이 메시지를 보낼 수 있는 권한이 있는 채널이어야 합니다.
* `python-dotenv` 라이브러리가 필요합니다.
* 공지사항 비교 상태는 기본적으로 `bot_data/notice_state.json`에 저장됩니다.
